# ADR 0009: 采用 VOFA+ 级联右键菜单与变量选择器重构控件通道绑定机制

## 状态 (Status)
**已接受 (Accepted)** - 2026-09-27

## 背景与上下文 (Context)
在先前设计中，控件的数据绑定主要依赖两种途径：
1. 从右侧通道侧边栏向控件拖拽绑定；
2. 在双击弹出的属性配置抽屉中，通过原生文本输入框（`<input type="text">`）手动键入通道标识（如 `actual`、`!0`）。

根据用户实测反馈与 VOFA+ 实测截图（`media_1790475343282.png`），手动键入通道存在严重体验痛点：
- **易输错且无提示**：工程师需要记忆下位机当前发送了哪些通道、大小写是否匹配，手动敲键盘极易产生拼写错误；
- **缺乏直接上下文入口**：在 VOFA+ 中，工程师最常用的操作是鼠标右键点击任意控件，直接看到 `📈 绑定通道 -> !4 ▶` 菜单项，hover 或点击即可展开当前全部存在的变量列表，点击即可完成绑定，操作极速且符合直觉。

## 架构决策 (Decision)

我们决定彻底重构工作台中所有控件的通道绑定交互方式，全面向 VOFA+ 原生交互靠拢：

### 1. 右键上下文菜单新增「绑定通道」级联子菜单 (ChannelBindingMenu)
- 右键点击任何控件时，上下文菜单展示项：
  - `📈 绑定通道 -> [当前通道] ▶`（如 `📈 绑定通道 -> !4 (速度反馈) ▶`，若未绑定则显示 `📈 绑定通道 -> 未绑定 ▶`）；
- 鼠标悬停或点击该项时，向右（或自适应视口向左）展开级联子菜单：
  - **单值控件（表盘、滑块、旋钮、数字框、指示灯、统计卡）**：
    - 列出当前活跃通道与预设通道（`!0` ~ `!7` 及用户别名）；
    - 每个条目显示：通道色彩圆点、通道标识（如 `!4`）、别名、当前 6 位高精浮点实时值；
    - 当前已绑定的通道带有明显单选标记（●）；
    - 点击任意通道，即刻完成重新绑定，右键菜单平滑自动关闭；
    - 底部提供 `🚫 清除绑定` 选项。
  - **多通道控件（波形图 ChartWidget）**：
    - 列表项支持复选框（☑️ / ⬜）；
    - 点击直接切换对应曲线在波形图中的激活与显示状态，实现毫秒级快速通道增删。

### 2. 属性配置弹窗全面推行「变量选择器」替代自由填空 (VariableBindingSelector)
- 在双击控件打开的配置抽屉中，所有涉及数据通道配置的字段（如仪表盘的“绑定通道”、滑块的“反馈回显通道”、双环系统的通道映射）：
  - 彻底移除文本输入框 `<input type="text">`；
  - 统一替换为定制的通道下拉变量选择器（`VariableBindingSelector`）；
  - 下拉选单中分类呈现已检测到的动态通道、工程注册通道与标准通道，展示颜色标牌、编号与实时值。

### 3. 冷启动与动态数据感知策略
- 系统默认常驻保障 `!0` ~ `!7` 以及当前 `ProjectModel` 中声明的拓扑通道；
- 串口一旦收到数据流，`globalChannelStore` 自动将新解析出的通道追加至选择器列表，并实时刷新翻滚数值；
- 无论串口是否连接，工程师均能无缝完成通道预排版与绑定。

## 收益与影响 (Consequences)
- **零输入成本**：告别键盘打字输入通道名，100% 鼠标点选即生效；
- **与 VOFA+ 行为绝对统一**：完美复刻截图中的经典交互体系；
- **状态透明可见**：右键菜单直接预览当前绑定的通道和实时数据，无需点进多级设置。
