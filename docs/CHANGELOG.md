## [Unreleased] - 2026-10-01

### 主工作区反馈执行与普通发送

- 参数实验、软件停止和协议切换时，终端普通发送提前禁用并显示原因，保留输入草稿；Enter / Alt+S 与普通快捷命令采用相同门槛，危险命令的软件停止入口继续可用。未连接时普通发送禁用，App 和传输层权限检查保留。
- 新增独立 5197 来源的实际 App 反馈夹具：真实 WebSerialTransport 和 module Worker 解析 ReadableStream 字节，真实 WritableStream 决定 written / failed；本地确定性 HTTP 响应提供合成候选。覆盖有限授权、提前 ACK、旧 ID、写失败、普通发送互斥、收起侧栏及两种停止入口。
- 原始 ACK 接收序号、原生 queued/result、异步写入权重新获取及真实硬件仍分别列为待验收；合成目标达到不表示真实设备调参成功。执行说明见[主工作区反馈验收](APP_FEEDBACK_ACCEPTANCE_2026-10-01.md)。

### 场景双路线与执行方式

- 调参路线显示为“AI 遥测反馈 / 物理模型计算”，反馈执行方式紧邻路线选择。重复选择当前路线、场景、控制方案、控制器、模型来源或确认方式不重写配置，不作废原候选；真实变化仍保留候选失效检查。
- 每个计划在面板生命周期内保存反馈执行偏好；模型路线使用人工方式，返回反馈时人工确认强制人工执行，其他确认恢复此前选择，未知偏好默认人工。选择 ACK 或参数回传不会隐式开启自动方式，自动试验仍须完整配置及本次授权。
- 模型路线将设备执行设置默认折叠，保留计算必需的模型、方向、周期与设计目标。候选入口展开父层及执行子区，计算缺项入口仅返回计算配置；服务入口仅用于反馈或 AI 草拟模型，结果区分别说明本机候选与设备试验状态。
- 增加独立 5196 来源的实际调参组件合成夹具，最终 19 项交互检查通过，视口仅 1280×720。PI 示例在剪切频率 1 rad/s 时拒绝无正增益解，用户改为 2 rad/s 后才生成候选；平衡车预设仅检查物理表单呈现。合计 1 次本地 mock HTTP，外部 AI、Jev 和设备写入均为 0。

流程、复现与证据边界见[场景双路线与设备执行流程](SCENARIO_FLOW_2026-10-01.md)。独立构建、提交和 CI 身份由冻结后回执核验，原生、硬件与在线模型仍未验收。

### 场景阶跃资格与候选状态

- 阶跃评价要求显式设定值容差、分离的平台与一次跳变，拒绝重复目标、斜坡和未稳定的初始反馈；旧配置缺值需补充，不猜测数值。上下行超调仅计算跳变后响应，最大超调支持严格的 0。
- 输出越界优先触发本地停止；大窗口极值改用循环，RMS 使用缩放平方和，非有限派生结果禁止进入 AI 依据。跟踪路线仍允许重复目标。
- 配置变化后候选与顶部状态同步作废，移除发送入口；设置与候选切换时滚动归零，显示候选依据与写入预览。
- 增加 27 项行为检查与独立 5195 来源的实际调参组件合成夹具。最终矩阵、冻结源码、构建和提交由本轮回执核验；本地 HTTP 不作为在线 AI 或硬件验收。

实现、流程和证据边界见[单次阶跃与候选状态](STEP_RESPONSE_ACCEPTANCE_2026-10-01.md)。

### 数据侧栏的身份与缓存状态

- 区分有限缓存读数、停止后的缓存、无有效显示值和明示等待绑定；原始 NaN/Infinity、非法 scale/yOffset 或变换溢出显示 `—`，不隐式转换成零。等待仅来自当前页配置字段，auto-bind 图表不生成等待，默认折叠，不从全部历史元数据或默认控制映射推断。
- 工作区加载恢复 owner-scoped 别名，读取 canonical/alias 共用实际缓存；只读呈现不创建持久化通道配置或 alias 缓冲，原始单位来源继续保留。冲突数量与唯一名称/canonical ID 修复提示可见，单位/缩放弹窗增加可键盘访问的名称修改入口。
- 待接收和无效绘图数值在显示边界按 `null` 缺口处理，保持原缓存；避免缺测 NaN 污染有限曲线坐标轴。最终显示边界交互结果由冻结验收回执确认。
- 动态颜色更新保留 uPlot 运行时 stroke 回调形式，修复全局隐藏/显示或重置显示配置时将其覆盖为字符串而触发 `s.stroke is not a function` 的浏览器异常。
- 收敛侧栏菜单，去除手动造零通道、含义不清的无数据清理及错误假定索引时间对齐的批量 CSV；图表保留自身范围导出流程，本轮没有新增跨通道同步导出验收。
- 增加独立 5194 来源的实际 App/合成 transport 夹具，覆盖首批次、零/非有限值、单通道/全部清缓存、新身份、断开及 reload 别名恢复。最终运行、构建和发布结果由冻结验收回执确认。

实现与执行步骤见[数据侧栏状态](CHANNEL_DATA_STATES_2026-10-01.md)。缓存状态不证明设备在线或数据新鲜，原生与硬件继续单独验收。

### 波形选区证据与回放结果归属

- 波形图支持拖选或输入精确起止秒数，再把选区冻结到同一 AI 调试助手。默认不上传；本地完整预览、主动勾选和点击分析分别执行，发送内容与本轮依据保存同一完整任务 JSON。
- 冻结证据保留真实通道 ID、用户提供的原始单位、会话/解析轮次/缓存世代及时间来源。统计覆盖全部有限所选缓存样本；原始数组最多 8 通道、每通道 256 点，保留有效首尾并计数无效值与限额省略。显示缩放和偏置不进入原始值。
- 新会话或解析轮次先清显示缓存再写入新批次，避免旧样本被标成新会话证据。请求及建议应用复核证据、会话、配置、协议、分析选项和取消状态，拦截迟到回复及过期应用。
- 通道名称显示保留 canonical ID；原始单位需用户核对后保存，和显示变换、控制执行单位分开。未声明单位的旧工作区继续可用。
- 回放 FFT 在通道、会话、解析轮次、时间来源或已读取输入变化时撤销旧结果；结果显示冻结归属，取消或卸载后迟到计算不能覆盖新视图。增加实际 Vue/module Worker 与实际 App/本机 HTTP 两个独立合成夹具。

实现与可执行验证见[波形证据与回放分析](WAVEFORM_EVIDENCE_2026-10-01.md)。本条记录源码变化；最终浏览器矩阵、独立构建、源码发布及 CI 结果由本次冻结验收回执记录，不表示原生、硬件或在线模型完成。

### 协议执行与驱动写入关联

- 场景候选冻结最终 UTF-8 可见文本、HEX、字节数和用户选择的转义 / 行尾格式；App 发送同一已审核字节。缺少有效字节契约的历史候选禁止发送。
- FireWater ACK 改为去除首尾空白后的完整 RX 行匹配，并要求本轮协议请求 ID；二进制协议使用数值参数回读或逐轮人工核对。执行绑定精确原始通道 ID，拒绝别名、未出现与重复通道。
- 设备确认分别核对派发日志 / ingestion revision 水位与驱动 written 回执，允许本轮 ACK 或一次性回读早于回执回调；不以主机回调时间戳推断设备因果。
- 新增 session 写入队列跟踪，实验锁取得后还需等待 queued 项的最终完整写入回执。普通命令提交撤销基线与观察窗口；排队、未知或停止锁定时不能确认基线和进入反馈，离线模型计算继续可用。
- 已派发未确认时停止，撤销当前参数与设备评价证据；增加 11 项 Vue 合成交互夹具的验证方案，冻结后实际结果另记回执，不作为原生、硬件或在线 AI 验收。

实现、可执行步骤和证据边界见[场景协议执行与写入关联](PROTOCOL_EXECUTION_2026-10-01.md)。

### 场景串级与反馈窗口
- 外环绑定同组前置内环的配置与顺序，内环改变后清除模型确认并作废旧候选；实际外环写入另外要求当前连接中的内环确认及完整达标评价。
- 飞控姿态物理模型从完整角速度内环闭环合成，明确微分滤波、反馈增益及单位变换，移除假定的单一内环带宽。
- AI 反馈严格选择当前 PID 与设备会话对应的完整观察窗口，保存时间范围和身份副本；历史试验不能恢复当前证据。失败窗口后允许显式重新核对基线。
- 授权等待前后和评价末跳复核范围、参数与设备身份；样本对齐使用排序索引及二分最近邻，避免满缓存时逐点全扫描。

使用流程、连续模型限制和硬件待验收项见[串级依赖及反馈窗口](SCENARIO_CASCADE_2026-10-01.md)。

### 控制计算与依赖证据
- 串级外环对象使用完整连续 PID 与常数反馈增益合成；保留原始特征多项式和控制方向，拒绝未证明稳定的内环、把反馈延迟移到闭环外部以及用单值带宽猜测闭环对象。外部惯性/积分环节要求明确物理参数。
- 带宽阈值使用计算值，缺失频率/采样周期、空拓扑、重复身份和采样告警不会跳过或默认通过。向导不再按层级填入典型带宽与默认 1ms，显示真实模型计算来源和待提供状态。
- 新增本地依赖许可事实清单、原文本通知候选和严格待审核门槛；固定数据库的 Rust 公告扫描保存锁文件/工具/数据库身份与告警，支持绑定独立构建。正式发行入口增加两项严格门槛，当前待审核状态仍为非零。

计算反例、扫描范围、已知告警及后续验收见[控制与依赖修复记录](CONTROL_AND_DEPENDENCY_HARDENING_2026-10-01.md)。

### 主体数据一致性修复
- Web Serial 二进制批次保留每个协议帧的身份与顺序；同一主机接收时刻的多个帧不再互相覆盖，命名通道和稀疏非有限值维持对齐。Worker 与主线程兜底同步处理，接收统计按实际帧数计数，不捏造设备采样周期。
- 回放选择、关闭与重开拥有独立请求世代；较早请求不能覆盖新记录的页、解码器、错误或加载状态。返回页核对 sessionId 与 epoch，正常跨页残帧和失败重试继续可用。
- 移除未接入收发链路的 GBK / GB2312 / ASCII 编码选项；界面明确文本路径使用 UTF-8，HEX 字节直通，保持最终字节行为一致。
- 增加多帧适配至 ChannelStore 的回归、实际 Worker 源码回归、延迟回放控制器测试，并纳入日常检查。浏览器演示记录验证已读取块数、三通道样本与原始字节回放；不视作真实设备记录。

验证与边界见 [主体流程修复记录](PRIMARY_FLOW_HARDENING_2026-10-01.md)。源码与候选构建各自封存，原生交互、实际串口和硬件闭环继续待验收。

## [0.1.1-beta.1] - 2026-09-30

### 产品体验迭代
- 新增任务型 AI 助手：选择日志/通道摘要、预览发送内容、取消分析、保留本轮依据；结构化建议经过本地校验，命令仅填草稿，协议和显示控件逐项确认。
- 新工作区默认终端与波形共用，自动绑定真实收到的通道；原有布局保留，控制实验模板改为可选。显示控件默认不假定单位或固件变量。
- 模型、仿真与参数实验收进高级工具；FFT/阶跃/CSV 收进图表菜单，移除重复布局锁入口。
- 仿真对比统一字体、主题、布局与 Canvas 尺寸；删除合成的“实测曲线”和默认固件命令，仅接受来源、通道与当前会话匹配的实测指标。
- 停用没有通道语义/边界配置的自动数值“发散”告警，保留日志异常线索；助手不会因选择日志而自动请求在线服务。
- 本机 OpenAI 兼容服务支持无 Key；切换服务或地址不复用旧凭据。增加助手输出与精确草稿测试。

### 本轮优化
- 顶栏拆为工作区导航与连接/采集操作两层，使用清晰标签、统一图标和可键盘操作的软件停止按钮；最小窗口支持自适应排布。
- 统一暗色/浅色主题与调参工作台配色，改善文字对比、焦点提示、空状态和状态说明。演示会话明确标记为模拟数据。
- 调参、Copilot、记录库及部分分析/设置界面按需加载；清除动态/静态导入重叠，减少主入口体积。
- 修复 Vue 响应式协议配置跨 Worker 边界的克隆异常，清理启动失败 Worker，并补全浏览器遥测帧数、吞吐和字节统计。
- Rust 配置保存使用同步临时文件与 Windows 原子替换，避免替换期间主文件缺失；支持读取遗留恢复文件并保留损坏配置。
- AI HTTP 请求限制响应与提示大小，禁止自动重定向和 URL 携带凭据，改进鉴权、限流和服务错误提示；启用桌面 CSP。
- 增加独立 Beta 构建、完整检查日志、源码输入摘要、EXE/ZIP 哈希和旧发布程序保护。发行产物移至 `output/releases/`，避免被前端构建清空。

### 改进 (Changed)
- 记录回放现在提供隔离的只读波形分析入口：必须选择已读取通道，FFT 沿用统一 Worker 的时间质量门禁，并把会话、时间来源、区间、算法版本和 `source=replay` 写入分析溯源。
- 记录库显示最近分析证据；历史只保存可验证元数据，可重新打开仍存在的记录会话，不把历史元数据当作可恢复的分析数值。
- 分析历史读取增加结构校验，损坏的浏览器存储不会进入界面；回放通道筛选提取逻辑独立成可测试服务。
- Copilot、PID 阶跃诊断、日志解释和反馈调参统一走同一 AI 请求边界；桌面请求继续在 Rust/DPAPI 边界内读取密钥，Web 错误与模型列表错误统一脱敏。
- 日志解释请求增加有界证据窗口和常见令牌脱敏，弹窗在请求前显示发送范围；阶跃诊断移除伪造采样率，明确标记未知时间基准。
- Web 持久化配置不再保留 `api_key_configured` 的旧会话状态；刷新后需在当前页面重新输入 Key 才能请求云端服务。
- 调参手动候选的基线与模型字段改为在输入事件中同步最新值，修复首次输入可能读取旧 `v-model` 状态的问题。
- PI 候选不再被未使用 KD 项缺失的参数范围误拒；活动 PID 参数仍执行范围、步长和结构校验，非零不活动项仍会拒绝。
- 软件停止字符串入口固定按文本编码，二进制停止帧必须显式传入原始字节；停止提示区分本地提交和驱动写入待回执，避免误报设备已经停止。
- 记录器达到旧归档文件数量后不再停止写入；旧 CSV 镜像继续按文件大小轮转，原始会话记录队列中断会异步收尾并明确标记 `interrupted`，避免永久停留在收尾状态。
- BodeWidget 不再根据 `plant_family` 或模板参数生成相位裕度；只有环路保存有效辨识模型时才计算，并明确标记为模型预测。
- 便携构建继续使用独立 staging 目录，最新构建清单、EXE/ZIP 哈希和旧发布程序保护状态记录在实施台账中。

### 验证限制 (Known limits)
- 当前构建仍为未签名测试发行；真实串口、拔插、长时间采集、设备 ACK、执行机构和附带 EXE 原生窗口仍需具备桌面 RPC 与硬件的环境验收。
- 本轮已拆分主入口并消除导入重叠提示；精确体积、实际测试与运行证据以本次 `output/builds/` 和优化验收报告为准。

## [v0.1.0] - 2026-09-25

### 新增 (Added)
- **底层通信与流分流 (Transport & Pipeline)**：
  - 基于 Rust 原生串口引擎与 Windows SetupAPI 自动热插拔枚举；
  - 智能流分流器 (Stream Demuxer)，支持纯 CSV、Teleplot 键值与普通文本日志单通道自动分流；
  - 串口断开与异常掉电自适应捕获保护机制。
- **常规调试模式 (General Terminal)**：
  - ASCII / HEX 双模字符显示；
  - 毫秒级时间戳前缀、自动滚动锁定与日志导出功能；
  - 定时循环发送器与 CRC16/CRC32 硬件校验工具箱；
  - 快捷指令卡片管理系统。
- **AI 波形调参模式 (Waveform & AI Tuner)**：
  - 基于 uPlot 的毫秒级多通道高帧率曲线画布；
  - 阶跃响应自动捕获引擎，支持超调量 $M_p$、上升时间 $t_r$、调节时间 $t_s$、稳态误差 $e_{ss}$ 四大指标提取；
