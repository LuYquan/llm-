# 《LLM串口》阶跃指标定义与算法说明 (Metrics & Algorithms)

> **适用范围**：AI 波形调参模式下的自动阶跃检测引擎与四大性能量化指标计算  
> **理论参考**：经典经典控制理论（时域性能指标分析标准）

---

## 1. 核心数学模型与定义

在控制工程中，当目标设定值（Setpoint）发生突变时，被控对象（Plant）产生的时间响应称为**阶跃响应 (Step Response)**。

### 1.1 基础符号约定
- $t_{step}$：阶跃突变的触发时刻；
- $r_0$：阶跃发生前的目标初值（如 0 rpm）；
- $r_1$：阶跃发生后的目标终值（如 1000 rpm）；
- $\Delta = r_1 - r_0$：**阶跃幅度**（可正可负，$\Delta \neq 0$）；
- $y_0$：阶跃突变前系统的实际响应初始值；
- $y(t)$：系统在 $t$ 时刻的实际测量响应值；
- $y_{peak}$：在阶跃方向上出现的峰值极值（若为正阶跃取最大值，若为负阶跃取最小值）；
- $y_{ss}$：稳态响应测量值。取快照尾部稳定区间内 $N$ 个采样点的算术平均值（$N$ 默认取 20 点）。

---

## 2. 四大关键性能指标算法

```text
    y(t)
     ^                     y_peak (峰值)
     |                       /\
     |                      /  \     y_ss (稳态值)
r1 --+---------------------/----\---===================-- +2% 误差带
     |                    /      \ /
r0 --+                   /        V                       -- -2% 误差带
     |                  /
     |                 /
     |                /|
     +---------------+-------------------------------------> t
                   t_step   tr (10%->90%)
                   |<----->|
                   |<------------->| ts (调节时间)
```

### 2.1 超调量 $M_p$ (Overshoot)
表示系统输出超出最终稳态值的最大偏离程度，用相对于阶跃幅度的百分比表示：

$$M_p = \frac{y_{peak} - y_{ss}}{|y_{ss} - y_0|} \times 100\%$$

> **说明**：
> - 算法基于**真实阶跃响应幅度** $|y_{ss} - y_0|$ 计算，而非粗暴除以目标值。即使系统初始设定值不为 0（如从 500rpm 阶跃至 1000rpm），超调量计算依然严格准确；
> - 若响应曲线单调上升无回落极值，则 $M_p = 0\%$（无超调）。

### 2.2 上升时间 $t_r$ (Rise Time)
反映系统跟踪指令的响应敏捷度。定义为系统响应从初始阶跃幅度的 **10%** 变化至 **90%** 所经历的时间：

$$t_{10\%} = t \text{ 时满足 } y(t) = y_0 + 0.1 \times \Delta$$
$$t_{90\%} = t \text{ 时满足 } y(t) = y_0 + 0.9 \times \Delta$$
$$t_r = t_{90\%} - t_{10\%}$$

### 2.3 调节时间 $t_s$ (Settling Time)
反映系统从受扰动到恢复平稳的耗时。定义为响应曲线进入并**最终停留在**允许稳态误差带 $\pm \delta$ 内的最早时间点：

$$|y(t) - y_{ss}| \le \delta \cdot |\Delta|, \quad \forall \tau \ge t$$
$$t_s = t - t_{step}$$

- 误差带比例 $\delta$：默认采用 **$2\%$ 准则**（工业高精度控制）；系统同时支持切换为 **$5\%$ 准则**（快速收敛判定）。

### 2.4 稳态误差 $e_{ss}$ (Steady-State Error)
反映系统的静差控制精度。定义为目标值终值与系统最终实际测量值之间的绝对偏差：

$$e_{ss} = r_1 - y_{ss}$$

- 单位与被测物理通道单位保持一致；
- $e_{ss} > 0$ 表示实际值未达到目标值（欠调节/静差过大），$e_{ss} < 0$ 表示实际值过冲未回调。

## 3. 自动快照触发与边界机制

### 3.1 阶跃触发判定条件
系统在数据流中自动判定阶跃事件，需同时满足：
1. **幅度跃迁**：绑定的 `Target` 通道在单帧或极短窗口内变化量 $|\Delta| \ge \text{Threshold}$（阈值可配置，默认大于量程的 5%）；
2. **保持稳定**：目标值变化后，在该水平线上保持持续时间超过预设观察窗（默认 $\ge 1.0\text{s}$）。

### 3.2 精度与采样频率关系
时间相关指标（$t_r$ 和 $t_s$）的测量理论精度直接取决于**下位机的上报采样周期 $T_s$**：
- 下位机以 **100Hz** 上报时，采样间隔为 10ms，则上升时间的测量时间分辨率为 **10ms**；
- 若调试 FOC 电流环（响应时间在 1ms 以内），直接通过串口 100Hz 采样无法解析微秒级上升沿。对于此类极高速回路，推荐下位机在控制中断内将微秒级瞬态数据缓存至 MCU 内存，触发阶跃后批量上报。

### 3.3 算法适用与不适用场景

| 场景 | 是否适用 | 说明 |
|---|:---:|---|
| **方波脉冲阶跃** | ✅ 适用 | 最标准的使用场景 |
| **单向跳变阶跃** | ✅ 适用 | 如 0rpm $\to$ 1000rpm 或 1000rpm $\to$ 500rpm |
| **斜坡输入 (Ramp)** | ❌ 不适用 | 目标值缓慢连续变化，不属于瞬间阶跃 |
| **正弦扫描 (Chirp)** | ❌ 不适用 | 频域测试，无法计算单次阶跃时域指标 |
| **未进入稳态即连续打断** | ⚠️ 部分适用 | 上位机检测到新阶跃会打断前一次快照并发出警告 |
