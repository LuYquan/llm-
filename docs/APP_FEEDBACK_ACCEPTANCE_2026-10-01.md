# 主工作区反馈执行与发送状态

AI 调参保留在串口、终端与波形的主工作区旁。实验占用参数写入权时，普通终端发送按钮及普通快捷命令提前禁用，并显示“先停止实验，再发送普通命令”。输入草稿仍可编辑；Enter 和 Alt+S 使用相同门槛。软件停止锁定后显示恢复提示；协议切换和未连接状态也阻止发送。危险快捷命令仍保留软件停止入口，App 和传输层继续检查写入权限。

收起 AI 侧栏不会停止或卸载实验。顶栏显示“AI 实验运行中”，重新打开可查看同一实验。需要停止调参循环时使用“停止调参流程”；需要锁定普通发送并提交已配置的停止字节时使用顶栏“软件停止”。两者不能解释为设备已经停机。

## 可执行的软件集成检查

独立夹具：`tests/browser/app-feedback-harness.html`，服务：

```powershell
node tests/browser/app-feedback-harness.vite.mjs
```

打开 `http://127.0.0.1:5197/tests/browser/app-feedback-harness.html`。仅此来源保存合成配置，`navigator.serial` 只暴露夹具的 `ReadableStream / WritableStream` 字节端口，真实物理端口不会被打开。真实 App、串口会话、WebSerialTransport、Dedicated module Worker、协议解析、ChannelStore、AI 请求与调参状态机参与执行；不通过调参组件 props 注入伪造连接或 written。

每个分支从“准备分支并重载”开始；点击实际 App 的“连接 → AI 辅助 → 模型设置”，在 API Key 输入框填 `synthetic-fixture-key` 并保存。浏览器不会从保存配置恢复密钥。返回“场景调参”，展开“当前参数与写入边界”，勾选仅用于该合成环境的当前参数和稳定保护确认。等待当前参数对应的基线窗口，再点击“检查并启动自动反馈”，阅读并确认本次有限范围。

本地 HTTP 服务只接受 `app-feedback-` 模型、固定合成项目、当前 Web Serial 会话和有限大小 JSON。它返回基线参数增加 10% 的确定性候选；串口反馈是脚本数字序列，没有物理对象动力学，也不能评价真实模型质量。停止配置为可见转义文本 `STOP\n`，实际停止字节为 `53 54 4f 50 0a`。

| 分支 | 验收要求 |
| --- | --- |
| 取消有限授权 | 本地模型请求和参数写入均为 0 |
| 精准 ACK 两轮 | 恰好两次模型请求和两帧参数命令；下一轮使用已确认参数及对应窗口；评价指标对应当前轮 |
| ACK 先于 written | 实际解析 ACK 已到、写入尚未完成时，没有确认或评价；written 后允许继续 |
| 普通发送互斥及收起侧栏 | 输入普通命令后按钮禁用，Enter 不写入；侧栏收起仍显示运行状态，完成后可查看同一轮记录 |
| 旧 ID ACK | `previous-request` 无法确认当前轮；超时结束，无评价或下一轮 |
| ACK 后写入失败 | WritableStream 拒绝后，精确 ACK 也不能确认；无评价或下一轮 |
| 观察期间停止 | 在观察窗口内点“停止调参流程”；已发命令保留，当前轮未评价，无 completed 或下一轮；本操作未下发停止字节 |
| 写入未完成时软件停止 | written 之前点顶栏停止，立即锁定发送；晚到的 written 不恢复实验，之后仅提交配置的 STOP 帧；无参数确认、评价或下一轮 |

“记录实际 App 证据”导出可见 JSON，包含真实解析批次身份、端口捕获字节、真实 write Promise 回执、本地请求输入、持久化实验状态及运行错误。浏览器验收保留源文件哈希、DOM 和截图，再与独立构建输入比较。数量由本轮机器回执计算，不能把不同夹具的旧通过数量相加充当当前源码覆盖率。

## 证据范围及待完成项目

这组检查是浏览器中的合成软件集成，原生交互、Tauri queued/result 事件顺序、真实串口、拔插、部分写入、硬件保护及停机、在线 AI、纯净 Windows 仍待验收。合成端口的成功 ACK 和脚本目标达成不等于真实设备调参成功。

ACK 当前使用唯一轮次 ID、界面日志水位及 written 的会话身份进行关联。界面记录时间是派发时间；Worker / native 缓存后派发的同 ID ACK，尚未获得原始字节接收顺序的严格证明。后续验收应在候选预览后、真正写入前输入同 ID ACK，延迟批次派发，再检查是否误确认；修复应将驱动接收序号和真正派发边界贯穿协议、会话、App，不混用 Web 相对时钟、Rust 相对时钟及 Unix 时间。本文仅记录待复现的审计边界，不声称真实硬件已出现故障，也不豁免它。

异步独占写入权在停止后重新进入时的尝试身份，也需要专门回归。本轮的 Web Serial write 直接等待流完成，不能证明原生三秒结果等待分支。现有来源、构建、公告、许可证和设备验收仍分别记录，公开提交和 CI 成功不等于正式发布。

TypeSafe 分工：精确 ID、字节、数值范围、窗口身份与停止状态由代码验证；复杂分析和实现由 Codex 完成。本轮 Jev 调用为 0，不把本地确定性 HTTP 响应记为 Jev 或真实在线模型。
