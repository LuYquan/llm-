# 《LLM串口》产品与技术演进路线图 (ROADMAP)

> **当前版本**：v0.1.0  
> **更新时间**：2026-09-25  
> **状态标识说明**：
> - 🟢 **已实现 (Released)**：功能稳定可用，包含在当前版本中；
> - 🟡 **进行中 (In Progress)**：核心架构已就绪，正在进行工程落地或测试；
> - ⚪ **规划中 (Planned)**：已进入技术论证或设计阶段，欢迎社区贡献方案。

---

## 一、 通信传输层 (Transport & Communication Layer)

| 功能特性 | 状态 | 目标版本 | 方案考量与说明 |
|---|---|---|---|
| **物理串口自动重连与热插拔探测** | 🟢 已实现 | v0.1.0 | 基于 Windows SetupAPI 实时监听热插拔事件，断开后自动保护不闪退。 |
| **智能流分流器 (Stream Demuxer)** | 🟢 已实现 | v0.1.0 | 单物理通道下自动识别与分流 CSV、Teleplot 及纯文本日志。 |
| **经典蓝牙虚拟串口 (SPP)** | 🟢 已实现 | v0.1.0 | 支持 Windows 系统配对后自动生成的虚拟 COM 口透传。 |
| **低功耗蓝牙 (BLE GATT) 直连** | ⚪ 规划中 | v0.2.0 | 借助 Rust `btleplug` 或 Web Bluetooth，无需 Windows 复杂配对即可直连蓝牙低功耗外设并读写特征值。 |
| **WiFi / 以太网局域网透传 (Socket)** | ⚪ 规划中 | v0.2.0 | 提供 TCP/UDP Client & Server 模式，适配搭载 ESP32 或网口模块的机器人底盘无线调参。 |
| **CAN / CAN-FD 转接卡接入支持** | ⚪ 规划中 | v0.3.0 | 适配常见 USB-CAN 适配器协议（如 CANable、candleLight），直接解析电机反馈报文。 |

## 二、 算法分析与 AI 调参层 (Metrics & AI Tuner Layer)

| 功能特性 | 状态 | 目标版本 | 方案考量与说明 |
|---|---|---|---|
| **实时阶跃响应特征指标提取** | 🟢 已实现 | v0.1.0 | 自动截取目标值跳变区间，毫秒级计算超调量 $M_p$、上升时间 $t_r$、调节时间 $t_s$、稳态误差 $e_{ss}$。 |
| **离线经典控制理论规则诊断** | 🟢 已实现 | v0.1.0 | 纯本地运行，基于经典整定准则输出动态评分与定性改进建议。 |
| **在线大模型 (LLM) 深度调参闭环** | 🟢 已实现 | v0.1.0 | 兼容 OpenAI 标准 API 协议（支持 DeepSeek、Qwen、Kimi 等），结合物理机理生成推荐参数。 |
| **SafetyGuard 前置安全限幅防线** | 🟢 已实现 | v0.1.0 | 严格拦截 NaN、极值溢出与符号反转异常，杜绝大模型幻觉引发飞车事故。 |
| **系统辨识与传递函数拟合 (System ID)** | ⚪ 规划中 | v0.2.0 | 采集多组阶跃响应数据，通过最小二乘法反演拟合一阶惯性+纯滞后传递函数模型 $G(s) = \frac{K}{Ts+1}e^{-\tau s}$。 |
| **本地轻量级模型集成 (Local LLM / Ollama)** | ⚪ 规划中 | v0.2.5 | 适配 Ollama / 本地 GGUF 格式推理后端，在断网高保密实验室中依然提供深度机理建议。 |
| **频域 Bode 图与扫频响应分析** | ⚪ 规划中 | v0.3.0 | 支持正弦扫频激励信号生成与开闭环幅相频特性分析。 |

| 功能特性 | 状态 | 目标版本 | 方案考量与说明 |
|---|---|---|---|
| **自由拖拽网格画布与多 Tab 管理** | 🟢 已实现 | v0.1.0 | 20px 网格对齐、自动画布外扩扩展、标签页增删改查。 |
| **编辑态 / 运行态挂锁安全机制** | 🟢 已实现 | v0.1.0 | 运行锁定态（🔒）防误触修改布局；编辑态（🔓）防误触发控制指令。 |
| **270° 指针仪表盘 (GaugeWidget)** | 🟢 已实现 | v0.1.0 | 指数阻尼平滑旋转、危险量程区间标红、多单位支持。 |
| **多通道波形卡片 (ChartWidget)** | 🟢 已实现 | v0.1.0 | 最多 8 曲线同屏，Min/Max 极值降采样保证流畅帧率。 |
| **动作按键与 1s 倒计时危险保护** | 🟢 已实现 | v0.1.0 | 危险动作强制 1 秒确认倒计时，防止连击误操作。 |
| **双模滑块调参器 (SliderWidget)** | 🟢 已实现 | v0.1.0 | 支持松手即发与高频节流连续下发，支持键盘方向键精准微调与就地双击键入。 |
| **开关拨码器 (Toggle Switch)** | 🟡 进行中 | v0.1.1 | 专用于电机使能、激光指示等布尔型状态控制。 |
| **模式下拉选择器 (Dropdown Select)** | 🟡 进行中 | v0.1.1 | 专用于位置环/速度环/力矩环多运行模式的一键切换。 |
| **二维虚拟摇杆 (Virtual Joystick)** | ⚪ 规划中 | v0.2.0 | 支持 X/Y 轴双变量连续解算，直接操控移动底盘与云台机构。 |
| **面板模板导出与共享生态 (.vofa.json)** | ⚪ 规划中 | v0.2.0 | 支持将用户排布的仪表盘配置打包导出与一键导入，促进团队协作。 |

## 五、 如何参与贡献

我们欢迎社区开发者参与路线图中特性的设计与实现：
1. **提出功能建议**：在 GitHub Discussions 发起技术可行性讨论；
2. **提交 Pull Request**：请遵循 Conventional Commits 规范，并在提交前通过完整的自动化测试；
3. **编写示例固件**：欢迎为常用微控制器（如 MSPM0、CH32V、ESP-IDF）补充适配固件示例。
