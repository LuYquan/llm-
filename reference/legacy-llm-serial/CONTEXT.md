# 领域统一术语表 (Ubiquitous Language / Context)

本文档记录“LLM串口”系统中的核心业务概念与统一领域词汇，作为系统架构与代码命名的一致性基准。

---

## 1. 通信与会话领域 (Communication & Session)

| 术语 (Domain Term) | 英文标识 | 概念定义与业务语义 |
| :--- | :--- | :--- |
| **设备会话** | `DeviceSession` | 针对特定物理单片机或机器人控制器的连接配置集合，包含通信端口（COMx/BLE UUID）、波特率、通道映射、被控对象预设及历史 PID 快照。 |
| **会话管理器** | `SessionManager` | 负责多设备会话的增删改查、配置持久化（LocalStorage/SQLite）以及断线自动重连。 |
| **数据源** | `DataSource` | 统一的底层硬件 I/O 抽象 trait，封装具体的硬件物理传输（SerialPort、BLE、Mock 仿真源）。 |
| **原始日志抽屉** | `LogDrawer` | 界面底部可折叠的控制台终端，用于捕获和显示单片机上送的非波形文本日志（如 `[INFO]`、`[ERROR]`）以及十六进制原始报文。 |
| **流分流器** | `StreamDemuxer` | Rust 核心数据管线中的智能分路器，负责在单物理串口流中实时甄别波形数值行与系统文本日志行，分别派发至不同处理管道。 |
| **日志环形缓冲** | `LogRingBuffer` | Rust 内存中的文本日志队列（固定容量，如保留最近 2000 行），支持节流向前端推送，防止高频刷屏卡顿。 |
| **快捷指令** | `QuickCommand` | 工程师预设的一键发送文本或 HEX 报文（如 `RST\n`、`CALIB\n`），支持一键点击下发。 |
| **传输适配层** | `TransportAdapter` | 屏蔽底层宿主环境差异的通信抽象层，根据运行环境自动路由至 Tauri Rust 后端驱动或浏览器 Web Serial API。 |
| **网页串口** | `WebSerial` | 基于浏览器 Web Serial API (`navigator.serial`) 的轻量级硬件连接实现，使应用无需桌面环境即可在现代浏览器中直连硬件。 |

## 2. 数据管线与控制分析领域 (Data Pipeline & Control Analysis)

| 术语 (Domain Term) | 英文标识 | 概念定义与业务语义 |
| :--- | :--- | :--- |
| **数据管线** | `DataPipeline` | 从原始字节流到可视化与 AI 诊断的处理链路：`InputSource -> Parser -> RingBuffer/Decimator -> StepAnalyzer -> UI/AI`。 |
| **自动嗅探器** | `ProtocolSniffer` | 协议识别引擎，自动区分行文本 CSV 流、Teleplot 键值流、纯文本日志与二进制帧。 |
| **阶跃响应指标** | `StepResponseMetrics` | 从时序测量数据中自动计算出的控制工程量化指标，包含超调量 ($M_p$)、调节时间 ($t_s$)、上升时间 ($t_r$)、稳态误差 ($e_{ss}$) 与阻尼比估算。 |
| **被控对象模型** | `PlantModel` | 硬件系统的物理分类（如两轮自平衡车直立环、FOC 速度环、倒立摆），用于指导 AI 调参专家的物理推理方向。 |
| **语义绑定** | `SemanticBinding` | 将物理未知的数据通道映射为具体的控制逻辑身份（如 Target 目标值、Actual 实际响应、Output 控制输出），是阶跃特征提取的前置条件。 |
| **阶跃快照** | `StepSnapshot` | 由底层算法引擎在捕获到一次完整阶跃响应后，自动生成的包含原始数据截段与已计算指标的只读不可变记录包。 |

## 3. AI 专家与安全闭环领域 (AI & Safety Guard)

| 术语 (Domain Term) | 英文标识 | 概念定义与业务语义 |
| :--- | :--- | :--- |
| **AI 调参建议** | `TuningSuggestion` | LLM 根据阶跃指标输出的下一轮结构化推荐参数，遵循“建议而非提交（Suggest, Do Not Commit）”准则。 |
| **核准下发** | `ApproveAndCommit` | 工程师对 AI 建议进行人工审查确认后，将新参数打包为控制指令写入单片机的操作。 |
| **安全限幅器** | `SafetyGuard` | 软件本地最后的安全防线，在下发前检查参数是否存在极值、NaN 或符号反转，防止大模型幻觉导致硬件飞车。 |
| **紧急急停** | `EmergencyStop` | 全局最高优先级发送通道（空格键触发），**发送内容由使用者按自己硬件配置**，默认未绑定。未绑定时按键只给出明确提示且**不发出任何字节**；已绑定时跳过审批/限幅/冷却，但不跳过物理现实（未连接、未确认均须如实上报）。绝不自动声称设备已停机。详见 [ADR 0004](docs/adr/0004-emergency-stop-user-configured-slot.md)。 |
| **MCP 端点** | `McpEndpoint` | 基于 Model Context Protocol (MCP) 的标准对外服务接口，允许外部智能体（如 Cursor、Claude Desktop、Antigravity）远程调用波形指标查询与参数回写工具。 |
| **双模 AI 体系** | `DualModeAi` | 兼具“应用内一键调参交互卡片”与“外部 IDE 智能体通过 MCP 协同控制”的混合架构设计。 |

## 4. 可视化控件工作台领域 (Control Widget & Dashboard)

| 术语 (Domain Term) | 英文标识 | 概念定义与业务语义 |
| :--- | :--- | :--- |
| **控件工作台** | `WidgetDashboard` | 独立的可视化控制面板，采用 VOFA+ 式“左侧控件库 + 右侧自由拖拽网格画布”架构，允许工程师自由拖拽放置、调整尺寸和保存多个交互式控制元器件。 |
| **自由拖拽画布** | `DragCanvas` | 支持网格对齐、绝对/网格坐标定位、自由拖拽移动（Move）与边缘拉伸（Resize）的可编程交互工作台。 |
| **运行/编辑挂锁** | `CanvasLockState` | 画布右上角的挂锁开关：锁定态（🔒）仅响应硬件指令交互与动态刷新；解锁态（🔓）允许拖拽新增、调整尺寸与编辑数据绑定。 |
| **指针仪表盘** | `GaugeWidget` | 具备刻度弧线、数值标尺、高频旋转指针与红线警告区的模拟表盘控件，绑定实时数据流通道动态指示。 |
| **实时波形控件** | `ChartWidget` | 可在画布内任意尺寸放置的波形曲线视窗，绑定指定数据通道并绘制时序曲线。 |
| **动作按键** | `ButtonWidget` | 具备防抖与危险确认的瞬态动作触发按钮，点击时下发单次控制指令（如复位、使能、触发模式切换）。 |
| **滑块调参器** | `SliderWidget` | 提供范围滑动条（具备 Min/Max/Step 与物理单位），用户拖拽微调或松开时自动按照指令模板将浮点参数下发至单片机。 |
| **指令下发模板** | `CommandTemplate` | 控件绑定的参数填充表达式（如 `SET KP={val}\n`），在下发时由系统动态渲染 `{val}` 并受 SafetyGuard 安全限幅器拦截保护。 |
| **图标坞站** | `IconDock` | 界面左侧 40px 固定垂直侧边栏，集中管理连接配置、协议引擎、控件库抽屉与多 Tab 工程配置。 |
| **底部终端控制条** | `DockedTerminalStrip` | 界面底部常驻的紧凑双行交互条，包含流控状态、快捷指令、发送输入框以及平滑展开终端日志抽屉的触发器。 |
| **单画布多Tab体系** | `UnifiedCanvasWorkbench` | 彻底取消独立模式分屏，以 100% 视界多 Tab 画布为核心的 VOFA+ 纯正工作台范式。 |
| **右键通道绑定级联菜单** | `ChannelBindingMenu` | 控件右键上下文菜单中的快速绑定入口，直接显示当前绑定的通道（如 `📈 绑定通道 -> !4 ▶`），展开显示所有当前存在的变量供直接点选或多选。 |
| **变量选择器** | `VariableBindingSelector` | 替代传统文本输入框的通道选择组件，从工程与数据流已有的变量池中动态罗列通道编号、别名、专属颜色与实时高精浮点值，供工程师直观选择。 |

## 5. 自动化控制智能体与理论领域 (Control Agent & Theory Domain)

| 术语 (Domain Term) | 英文标识 | 概念定义与业务语义 |
| :--- | :--- | :--- |
| **控制副驾驶智能体** | `ControlCopilotAgent` | 融入常规调试中枢的专业自动化控制智能体，具备物理机理感知、频域分析与串级拓扑推演能力，作为主终端实时辅助调控工具。 |
| **传递函数模型** | `TransferFunction` | 复频域（$s$ 域）下输入与输出拉普拉斯变换之比 $G(s) = \frac{Y(s)}{U(s)}$，用于定量刻画电机的惯性、阻尼与滞后物理机理。 |
| **波特图频域分析** | `BodeAnalysis` | 开环对数幅频曲线与相频曲线分析，用于计算相位裕度与幅值裕度，指导理论最优参数的解析反算。 |
| **相位裕度** | `PhaseMargin` | 剪切频率处相角距离 $-180^\circ$ 的临界裕量 $\gamma = 180^\circ + \angle L(j\omega_c)$，直接决定系统阶跃响应的阻尼比与超调量。 |
| **串级控制系统** | `CascadeControlSystem` | 包含内环（如电流环/速度环）与外环（如位置环/角度环）的多层嵌套控制体系，遵循“先内后外、带宽分层递减”的整定法则。 |
| **控制器拓扑裁剪** | `ControllerPruning` | 依据物理对象特性对 PID 各项进行科学裁剪的工程范式（如电流/速度环禁用微分项以抗噪声，外环使用纯 P 以防超调冲击）。 |
| **控件全融合画布** | `WidgetUnifiedCanvas` | 遵循 VOFA+ 纯正哲学的交互范式，彻底取消“波形独立窗口”，将高帧率时序波形作为控件库中的核心元器件任意拖拽排布。 |

## 6. 视觉设计系统与主题领域 (Design System & Theming Domain)

| 术语 (Domain Term) | 英文标识 | 概念定义与业务语义 |
| :--- | :--- | :--- |
| **Claude 人文极简美学** | `ClaudeHumanisticAesthetic` | 软件系统的视觉主基调，借鉴 Anthropic Claude 风格，以温润燕麦暖白与浓缩咖啡暖深灰为底色，陶土赤陶橙为标志性交互强调色，追求克制、舒适、无视觉疲劳感的学术与工程质感。 |
| **双模温润主题** | `DualWarmTheme` | 支持一键切换的两种温润主题体系：【Claude 优雅暖黑 (Warm Espresso)】（夜间工作深灰低对比度护眼）与【Claude 经典暖白 (Warm Alabaster)】（高采光环境下书刊纸张质感）。 |
| **自然温润色系** | `NaturePalette` | 示波器通道曲线的专用配色集合，彻底取代传统高刺眼荧光绿与电光蓝，采用陶土红（`#CC785C`/`#DA7756`）、鼠尾草绿（`#5E8B7E`）、石板蓝（`#587B94`）、暖琥珀（`#D97706`）与静谧紫（`#7C3AED`）。 |
| **悬浮微卡片控制条** | `FloatingPromptPill` | 借鉴 Claude 对话输入框范式的单行底栏交互容器，具备 `rounded-2xl` 柔和圆角、四周微留白透气与标志性圆形陶土色发送按键。 |
