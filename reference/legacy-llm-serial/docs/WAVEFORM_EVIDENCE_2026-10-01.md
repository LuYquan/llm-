# 波形选区证据与回放分析

本次把 AI 调试从“先填写问题”延伸到“从正在观察的波形准备证据”。串口、终端与波形仍是主工作区；选区只打开现有 AI 辅助中的调试页，不建立独立工作台，也不授予发送或调参权限。

本文记录源码实现、已观察的合成反例及复现方式。文档冻结时，最终浏览器矩阵、独立 Beta 构建、源码发布和对应 CI 回执仍由主任务收尾记录。此前构建和 CI 不能证明本次改动已验收。

## 用户流程

1. 收到波形后拖动选择区间，或打开图表“分析与导出”，输入“选区起点（秒）”与“选区终点（秒）”，点击“选定区间”。时间使用图表原始秒轴，必须有限、有序并处于当前视窗。
2. 点“选区交给 AI”。助手显示本地图表证据、来源、时间范围、真实通道 ID、用户声明单位以及统计和取点数量。这一步不启动模型请求。
3. 打开“查看冻结选区 · 本地预览”核对完整冻结 JSON。选区附加选项默认关闭，每次重新选择都重置为关闭；“移除选区”撤销当前准备的证据。
4. 需要发送选区时，勾选“附加此选区的统计与原始样本（最多 8 通道、每通道 256 点）”，检查“查看发送内容”，再点击“分析任务”。未勾选时仍可分析任务、日志或通道摘要，但请求中没有 `evidence.chartSelection`。
5. 建议生成后逐项审阅。命令只允许“确认填入草稿”，最终发送仍在终端由用户完成。改变证据、会话或配置后，旧建议保留用于查看，不能继续应用。

## 证据和本地判断

`ChartWidget.vue` 解析曲线绑定所指向的真实原始缓存，按 canonical ID 去重，读取精确秒范围的原始快照。`App.vue` 提供演示/当前串口缓存/未核实来源和明确的时间说明，并在新设备会话或解析轮次进入前清空旧显示缓存；原始记录存储不因此删除。清缓存、断开或新身份批次撤销当前选区。

`evidenceSelection.ts` 生成独立、深度冻结的普通对象；后续原缓存和元数据变化不会修改已经选中的数值。会话 ID、解析轮次、缓存世代、来源、时间来源和图表身份随证据保存。有限且非逆序的时间轴才可冻结；非有限数值被排除并计数，没有有效点的通道拒绝冻结。相同时间戳的原样本保留，不插值或合并。

| 字段 | 含义 |
| --- | --- |
| `range` | 用户选定的精确原始秒范围 |
| `channels[].canonicalId` | 真实绑定身份；显示名称不替代它 |
| `unit` / `unitSource=user` | 用户核对后的原始数据单位声明；不代表固件自动证实 |
| `counts.selected` / `valid` / `rejectedNonFiniteValues` | 当前缓存中所选点数、有效点数和拒绝的非有限值数量 |
| `summary.scope=all-finite-samples-in-selected-cache` | 全部有效选区缓存的统计，不是仅对上传数组统计 |
| `counts.retained` / `omittedForLimit` | 限额保留与省略的有效原始点数 |
| `samples` / `sampling` | 最多每通道 256 点；超过限额时按原索引均匀取点并保留有效首尾 |

最多保留 8 个 canonical 通道，输入快照每通道最多 50,000 点。限额数组使用原始数值，不能保证时间均匀，也不能保证保留尖峰、频率成分或完整动态。统计仅代表选定范围内当前显示缓存的有效样本；它不等于完整串口记录，也不证明物理模型、设备采样时钟或控制参数有效。

通道配置增加可留空的原始单位，保存非空单位前必须勾选“我已核对固件原始数据单位；这是用户提供的声明”。单位变动需要重新核对；清空时同时移除单位和来源。显示 scale/yOffset 继续只影响图表，不改变缓存、冻结原值或控制执行单位。旧工作区没有单位时不填入猜测值。浏览器检查发现配置弹窗受侧边栏层级限制而被图表遮挡，本轮一并将弹窗移出该层级，并补齐焦点和键盘关闭操作。

`DebugAssistantPanel.vue` 预览、发送和保存同一 `{task,evidence}` JSON 字符串。选区附加需要明确勾选，日志仍按既有范围进行凭据脱敏；原始数值不会自动脱敏。HTTP 回复返回及应用开始时立即核对会话、解析轮次、缓存世代、配置、协议、选区修订、任务和分析选项，取消也撤销归属。异步应用完成后再次核对，期间变化则提示“已开始的操作可能已完成”，不把它误标为可继续应用。

上述有效性、限额、归属和许可条件是本地确定性规则，由 Codex 实现和复核，不能交给模型授予执行权限。此前外发源码摘要的 Jev 请求被自动审批拒绝；本次没有重试或绕过，Jev 与外部 AI 调用均为 0。本机合成 HTTP 回复仅用于验证请求和界面流程，不是 Jev 或在线模型质量验收。

## 回放 FFT 修复

已在真实 Vue 组件及实际 module Worker 中复现：合成 A=5 Hz 的 FFT 完成后，把通道选择改为 B=11 Hz，界面仍显示 A 的 5 Hz。此前结果没有随仍然存在的通道选择改变而撤销。

修复以每次输入修订和任务 ID 归属结果。选择通道、会话、解析轮次、时间来源、读取区间、样本数量，以及原地样本/时间修改都会撤销旧结果和计算任务。结果展示冻结的通道、会话、轮次和时间来源；取消、清除和组件卸载也撤销归属，已计算但迟到交付的旧结果不能提交到新视图。

独立夹具保留实际 FFT 算法、Worker 和客户端，只在异步反例中延迟已经计算完成的 Promise 交付，并故意允许取消后的迟到交付。它用于检验组件的最后一次归属检查，不能当作真实设备时基的证明。

## 可执行验证

在项目根目录使用已安装的锁定依赖。缺少依赖时先执行 `npm ci`。以下两个服务器分别在独立终端前台运行；已有同端口夹具时复用该实例，不终止其他程序或改用用户日常页面的数据。

```powershell
node tests/browser/replay-analysis-harness.vite.mjs
```

打开 `http://127.0.0.1:5192/tests/browser/replay-analysis-harness.html`。先点“复现：计算 A 后选择 B”：修复后的预期是切换撤销旧结果。再点“运行归属与异步边界验证”，保存机器可读结果和真实 Worker 事件；每项结果应由实际运行记录确认，不以按钮存在或源码用例数量代替通过。

```powershell
node tests/browser/evidence-workflow-harness.vite.mjs
```

打开 `http://127.0.0.1:5193/tests/browser/evidence-workflow-harness.html`。这个独立来源挂载真实 `App.vue`，替换的仅是传输驱动和本机模型 HTTP 回复；预置数据是明确的合成工作区，没有读取用户记录或密钥。

1. 点真实 App 顶部“演示”，再点夹具“注入合成批次”。在图表“分析与导出”选择 `2` 到 `8` 秒，点“选区交给 AI”。
2. 核对 canonical 通道为 `actual`，别名显示为“姿态角 · actual”，单位为 `rad` 且来源 `user`；别名曲线显示 scale=10、offset=100，证据原值仍为约 `-0.5…0.5`。本次合成区间包含 601 个有限缓存点，限额数组保留 256 点；显示值不能进入原始数组。
3. 核对附加选区默认关闭。“记录当前证据”中的 HTTP history 应为空。直接点“分析任务”后，请求中应没有 `chartSelection`；勾选附加选区后再次分析，history 的 `rawUserMessage` 应逐字等于“查看发送内容”的 JSON，`state` 也保留同一冻结证据。
4. 通过“延迟下一次回复”准备迟到回复，在请求期间移除或重选区间，或点“新会话批次”，再“释放延迟回复”。旧请求不能生成当前可应用建议。正常回复生成后再改变任务、日志或附加选项，旧建议应变为仅可查看。新会话批次应先清旧缓存；新选区不能带着旧样本却声称属于新会话。
5. 正常回复只可填入测试草稿 `FIXTURE_STATUS`。核对终端草稿和 fixture `writeAttempts=0`；取消、会话/协议变化后的旧建议不能填入草稿。改变 AI 服务会涉及真实网络，不属于此合成夹具步骤。
6. 在暗色/浅色和不同窗口尺寸核对范围输入、冻结证据、发送预览与操作按钮，保存实际截图。日常图表拖选与原生窗口交互仍须按各自证据层记录。
