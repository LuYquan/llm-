## 本轮新增实现（T01/T03/T04 局部）

- 调参执行在父级显式传入 `executionEnabled=false`；手动候选和方案仍可编辑/审阅，但发送、确认、自动迭代和评价同时有界面及方法级门禁。写入结果区分 `queued` 与 `written`；排队状态不会进入设备确认或遥测评价。旧会话中无法追溯驱动回执的 `sent` 状态迁移成 `queued`。
- `sendSerialData()` 返回编码后的实际字节数和提交状态。Tauri 当前明确返回 `queued`，Web Serial 成功完成 WritableStream 写入时返回 `written`；二者均不代表设备确认。TX 计数仅在 `written` 增加；桌面暂时没有写入回执时计数显示 `—`。
- 移除 TauriTransport 从日志 `raw_hex` 或格式化文本合成 rawData 的实现；Web Serial 接收计数仅按真实 read chunk 字节数增长。波形点和文本长度不再冒充串口字节数；桌面原始字节计数在非记录状态下仍未接通。
- HEX、中文/UTF-8、文本转义、追加 CRLF 和非法字节输入由共享编码器处理；桌面和 Web 使用同一编码结果。
- 软件停止字符串入口不再根据内容自动猜测 HEX；需要二进制停止帧时必须传入已校验的原始字节。界面提示也明确区分“提交到本地发送线程”和“驱动写入回执”，不把排队当作设备已停止。

## 本轮新增实现（T02/T06 局部）

- 每次用户发起新串口连接前清空易失实时显示缓存、速率与当前分析卡片；不触碰磁盘记录。图表监听缓存清空事件，即使全局暂停绘图也会立即移除前一会话画面。调参遥测快照在断开时清空。
- RingBuffer/ChannelStore 提供不复制样本的时间边界；图表只读取配置时间窗，并对错频样本按时间戳并集排列，缺失样本显示为空隙。存在非单调时间输入时对绘图快照作排序保护。
- 显示采用每桶 min/max 降采样并保留首尾点；错频、缺失、乱序点和奇数点预算均有纯函数测试覆盖。全局暂停接入 `GlobalRenderScheduler.setPaused()`，不会停止串口采集或记录；缩放/平移的 window 监听在控件卸载时移除。
- 波形 CSV 从通道环形缓冲的完整所选区间重建；写出原始值与 17 位有效数字时间/数值，包含稳定通道 ID 与 CSV 引号处理，并阻止公式型通道名称直接作为公式执行。此导出仍仅覆盖内存保留区间，不含磁盘会话记录回放。
