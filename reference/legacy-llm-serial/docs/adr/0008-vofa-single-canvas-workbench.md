# ADR 0008: 全面转向 VOFA+ 单画布工作台体系（废除三模式独立分屏）

## 状态 (Status)
**已接受 (Accepted)** - 2026-09-26

## 背景与上下文 (Context)
在原有设计（ADR 0001、ADR 0007）中，系统采用了三模式顶层切换（`纯终端视角`、`终端+波形调参`、`终端+控件仪表`），并在后两者中强行采用了左侧 55% 终端 + 右侧 45% 扩展视区的左右分屏布局。

经过实际工程使用走查与用户反馈发现：
1. **模式割裂且逻辑重复**：所谓的“波形调参”和“控件仪表”本质上都是 VOFA+ 范式中的画布应用。在 VOFA+ 中，波形本身就是一个全屏或自定义尺寸的 `ChartWidget`，将其割裂为独立模式导致概念重复。
2. **终端过度侵占横向空间**：在进行波形监控或多控件联动时，左侧 55% 固定宽度的终端日志大量闲置，严重挤压了波形与仪表的展示视区。
3. **交互心流不连续**：工程师在波形监控与仪表控件之间来回切换 Tab，违背了 VOFA+“所有控件自由拖拽组合在同一画布上”的直觉体验。

## 架构决策 (Decision)

我们决定彻底重构工作区主布局，全面拥抱 **VOFA+ 单画布多 Tab 体系**：

### 1. 彻底废除三模式顶栏与左右固定分屏
- 移除顶部的“纯终端”、“终端+波形”、“终端+控件”三模式 Tab 切换器。
- 移除主工作区 55% : 45% 左右分屏容器，主视窗视区 100% 由多 Tab 画布接管。

### 2. 左侧 40px 垂直侧边栏（Icon Dock）与抽屉系统
- **固定竖向 Dock（40px 宽）**：
  - `🔌 连接与端口`：点击滑出串口/传输配置抽屉；
  - `⚙️ 协议引擎`：点击滑出协议选择（RawData / FireWater / JustFloat）与帧配置抽屉；
  - `🧩 控件库`：点击滑出控件库抽屉，展示 Chart、Gauge、Slider、Button、StatCard、StepResponseCard 等元器件；支持直接按住鼠标拖拽控件至主画布；
  - `📁 画布与工程`：管理多 Tab 增删、导入导出 JSON 工程布局。

### 3. 主视窗：100% 自由多 Tab 画布（Unified Canvas）
- 画布支持运行/编辑挂锁（🔒 / 🔓），网格吸附与边缘缩放。
- 提供开箱即用的预设 Tab：
  - **Tab 1「实时波形」**：画布内放置一个全屏自适应的旗舰级 `ChartWidget`（包含 uPlot 高帧率流式渲染、通道显隐、阶跃捕获、十字光标、测量标尺）；
  - **Tab 2「控制联调台」**：预设 `ChartWidget` + 3 个 PID `SliderWidget` + 模拟 `GaugeWidget` + `StepResponseCardWidget`。
- 允许用户自由新建空白 Tab，从左侧库拖拽任意控件搭建专属面板。

### 4. 底部双行紧凑型终端交互条（Docked Terminal Strip）
- **第一行（状态与流控条）**：
  - 采样控制：启动/暂停、清空缓冲、数据点计数；
  - 通道快显：活动通道指示灯；
  - Copilot 诊断胶囊：收起态显示当前控制环路状态与最近异常；
- **第二行（极简发送与控制条）**：
  - 格式切换（ASCII / HEX）、换行符选项；
  - 单行发送输入框 + 发送按钮；
  - 常用快捷指令横向胶囊按钮；
  - `展开终端日志 ▲` 按钮：点击后从底部平滑滑出全功能终端日志抽屉（高 30%~50% 可拉伸），关闭即收回，绝不侵占主画布常驻空间。

### 5. Copilot 控制智能体深度融入
- 平时作为底部抽屉与状态条存在，检测到单片机 HardFault、断言报错或电机持续发散震荡时，在发送栏上方弹出**事件报警胶囊**。
- 展开后展示完整对话、系统辨识参数、Bode 频域裕度分析卡片，并提供“填入发送区”按钮，杜绝智能体自动发送的危险。

## 收益与影响 (Consequences)

### 积极收益 (Positive)
- **纯正 VOFA+ 体验**：老用户无需任何学习成本，即拖即用，完全符合嵌入式工程师直觉。
- **空间利用率最大化**：波形与仪表享受 100% 全屏视界，微调与观察一目了然。
- **架构纯度提升**：视图层完全统一为 `WidgetDashboard`，消除原来两套波形渲染代码的冗余，单一全局 `ChannelStore` 与 `rAF` 统一调度。

### 潜在代价与缓释 (Trade-offs & Mitigations)
- **日志阅读需展开抽屉**：普通打印调试时需展开底部抽屉。
  - *缓释措施*：支持快捷键（如 `Ctrl + ~` 或一键点击）秒级切换抽屉状态；在底部控制条保留最新 1 条状态摘要。
