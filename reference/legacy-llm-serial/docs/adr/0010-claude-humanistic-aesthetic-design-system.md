# ADR 0010: 采用 Claude 人文极简美学重构工作台视觉设计系统与双模架构

## 状态 (Status)
**已接受 (Accepted)** - 2026-09-29

## 背景与上下文 (Context)
随着《LLM串口》单画布多 Tab 架构与 VOFA+ 交互逻辑的逐步完善，系统功能已高度完备。然而，原有的前端视觉风格依然残存着传统工控上位机或生硬深黑电竞风格的痕迹：
1. **视觉疲劳度高**：大范围纯冷死黑底色搭配高频高对比的霓虹蓝、荧光绿曲线，导致嵌入式硬件工程师在长时间调试波形、分析日志时眼部极易酸胀疲劳；
2. **元器件与工具质感脱节**：市面上的工控工具通常偏向粗糙、重度的拟物化（如刻意添加厚重的假金属滚花反光），而现代优秀工程软件（如 Claude、Linear、Raycast）均已证明：现代高阶工具的美学核心在于**克制、透气、自然与高精度**。
3. **用户明确诉求**：经过交互原型对比与审查，用户明确裁定“仿造 Claude 风格”为系统最终唯一钦定的前端视觉基调。

## 架构决策 (Decision)

我们决定将《LLM串口》前端视觉体系彻底重塑为 **Claude 人文极简美学 (Claude Humanistic Aesthetic)**，具体决策如下：

### 1. 双模温润色彩系统 (Dual Warm Palette)
- **优雅暖黑模式 (Warm Espresso / 默认启动模式)**：
  - 基底底色：`#1F1E1D`（浓缩咖啡深灰，绝非纯冷黑）；
  - 卡片表面：`#272623`；次级高阶表面：`#2F2E2A`；
  - 边界线条：微细温暖灰边 `#383633`、聚焦边框 `#4A4843`；
  - 核心点缀色：Claude 标志性陶土红/赤陶橙（`#DA7756`）。
- **经典暖白模式 (Warm Alabaster / 顶部一键切换)**：
  - 基底底色：`#FAF9F5`（温暖燕麦纸质感）；
  - 卡片表面：`#FFFFFF`；次级高阶表面：`#F5F4EF`；
  - 边界线条：`#E8E6DF`、聚焦边框 `#D5D3CB`；
  - 核心点缀色：Claude 标志性陶土红（`#CC785C`）。
- 顶部导航栏右侧提供 **`[☀️/🌙]`** 极简切换胶囊，记忆用户当前偏好并写入本地存储。

### 2. 自然温润示波通道调色板 (Nature-Inspired Waveform Palette)
- 废弃原本刺眼廉价的高饱和电光色；
- 全局通道默认配色全面升级为：
  - 通道 0：`#CC785C` / `#DA7756` (Claude 陶土红)
  - 通道 1：`#5E8B7E` / `#7AA89B` (自然鼠尾草绿)
  - 通道 2：`#587B94` / `#759CB5` (石板灰蓝)
  - 通道 3：`#D97706` / `#E59E38` (温暖琥珀)
  - 通道 4：`#7C3AED` / `#9D6CF0` (静谧紫罗兰)
- 确保波形无论在暖白还是暖黑背景下，均具备出色的色彩对比度与柔和护眼特性。

### 3. Claude 悬浮微卡片控制条 (FloatingPromptPill)
- 底部 38px 单行交互条重塑为类似 Claude 悬浮 Prompt 框的圆角微卡片结构：
  - 外观四周具备轻微透气留白，采用 `rounded-2xl`（16px）柔和圆角与温润微阴影；
  - 内部无缝集成 `Abc/HEX` 微格式胶囊、单行输入框、常用指令微药丸；
  - 发送按钮采用 Claude 标志性陶土色实心圆形发送按键（`↵`）。

### 4. 极简元器件人文扁平化升级
- **仪表盘 (GaugeWidget)**：采用纯净的几何微弧线（8~10px）搭配纤细刀锋指针，移除所有刺眼的渐变金属拟物边框；
- **调参滑块 (SliderWidget)**：柔和轨道搭配标志性陶土色圆角拇指键，拖拽时浮现精密数字 Tooltip；
- **AI Copilot 诊断卡片**：仿造 Claude 对话回复的优雅排版，搭配精致星芒徽标。

## 收益与影响 (Consequences)
- **行业独创性**：成为业界首个具备 Claude 人文学术美学的嵌入式控制调试工作台；
- **长时间使用零疲劳**：温和纸质暖白与浓缩咖啡暖黑极大缓解工程师在强光或夜间测试时的眼部压力；
- **操作心流自然连贯**：悬浮 Prompt 底栏与对话式 AI 紧密融合，整体软件气质温和高级。
