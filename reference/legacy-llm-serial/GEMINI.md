# Project Guidelines - LLM串口

## Grilling & Requirement Interviewing Rules
Whenever asking questions to clarify requirements, gather feedback, or run `/grill-me` / `/grill-with-docs`:
1. **Always use the native `ask_question` tool** so the user receives the interactive modal in the UI.
2. **Never print multiple-choice questions as markdown text** in chat.
3. Put recommended options first with `(Recommended)`.
4. Allow user write-in feedback through the modal's native custom input field.
